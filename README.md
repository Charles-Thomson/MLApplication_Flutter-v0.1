Flutter Front-End for ANN Learning Application
This Flutter application provides a user-friendly graphical interface for interacting with an Artificial Neural Network (ANN) learning system.

Features:
Configure and select neural network and environment parameters

Set training hyperparameters for ANN models

Interact seamlessly with the backend via a GraphQL API

Notes:
Designed for intuitive setup and experimentation with machine learning configurations

Optimized for responsiveness and cross-platform use
